Basically we are given an unsorted array which has only 3 types of entry, 0,1 and 2
nums = [2, 0, 2, 1, 1, 0]
We need the array to look sorted like this:
nums = [0, 0, 1, 1, 2, 2]


Using DNF, Dutch National Flag Algorithm, we have used the code below:

public class Solution {
    public void sortColors(int[] nums) {
        int low = 0;                // Start of the array (for 0s)
        int mid = 0;                // Current index we're checking
        int high = nums.length - 1; // End of the array (for 2s)

        while (mid <= high) {       // Checking & keeping on going until the 
            if (nums[mid] == 0) {
                // If the number is 0 (red), put it in the front
                swap(nums, low, mid);
                low++;
                mid++;
            } else if (nums[mid] == 1) {
                // If it's 1 (white), it's already in the middle
                mid++;
            } else {
                swap(nums, mid, high);
                high--;
                // Don't increase mid here, because swapped value might need checking
            }
        }
    }

    // Helper method to swap two elements in the array
    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
