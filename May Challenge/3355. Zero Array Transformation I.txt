A Zero Array is an array where all elements are equal to 0.

We are given an array of length n & a 2D Array queries where queries[i] = [li, ri].

For each queries[i]:

1)Select a subset of indices within the range [li, ri] in nums.
2) Decrement the values at the selected indices by 1.

if it's possible to change the query array to a Zero Array, return true, if not return false.

Solution:
import java.util.*;
class Solution {
    public boolean isZeroArray(int[] nums, int[][] queries) {
        int n = nums.length;

        int[] freq = new int[n+1]; //frequency initialization, to keep track how many times each index is included in query ranges.

        for(int[] q:queries){
            int l = q[0], r = q[1];
            freq[l]++;              
            if(r + 1 < n) freq[r + 1]--;  //For each query [l, r], we increase freq[l] and decrease freq[r + 1].
        }
        for(int i = 1; i < n;  i++){
            freq[i] += freq[i-1];
        }
        
        for(int i = 0; i < n; i++){
            if(nums[i] > freq[i]) return false;
        }
        return true;
    }
}
