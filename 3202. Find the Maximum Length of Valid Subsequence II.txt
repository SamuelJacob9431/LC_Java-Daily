3202. Find the Maximum Length of Valid Subsequence II

A subsequence is formed by removing zero or more elements from the array without changing the order.

For example, from [1, 2, 3, 4, 5], valid subsequences include:

[1, 2, 3]

[2, 4, 5]

[1, 3, 5]

[1, 2, 3, 4, 5] ← the full array is also a subsequence

 Given:
An array nums of integers.

An integer k (positive).

You are to find a subsequence sub (not necessarily contiguous) of nums that satisfies a specific condition:

For every pair of consecutive elements in the subsequence, the sum of the pair modulo k must be the same throughout, holding true to the formula for all consecutive elements:
(sub[0] + sub[1]) % k == (sub[1] + sub[2]) % k == ... == (sub[x - 2] + sub[x - 1]) % k.

Your Goal:
Return the maximum length of any valid subsequence that satisfies the above modulo condition.

Java Code:
class Solution {
    public int maximumLength(int[] nums, int k) {
        int n = nums.length;
        if (k == 1) return n;

        int res = 2;
        int [] modArr = new int [n];

        for (int i = 0; i < n; i++)
            modArr[i] = nums[i] % k;
        
    
        for (int j = 0; j < k; j++){
            int [] dp = new int[k];
            for ( int i = 0; i < n; i++){
                int mod = modArr[i];
                int pos = ( j - mod + k) % k;
                dp[mod] = dp[pos] + 1;
                res = Math.max(res, dp[mod]);
            }
        }
        return res;
    }
}

Python Code:
class Solution:
    def maximumLength(self, nums: List[int], k: int) -> int:
        dp =[[0] * k for _ in range(k)]
        maxLength = 0


        for num in nums:
           current_rem = num % k

           for prev_rem in range(k):
              dp[prev_rem][current_rem] = dp[current_rem][prev_rem] + 1      

              maxLength = max(maxLength, dp[prev_rem][current_rem])

        return maxLength
