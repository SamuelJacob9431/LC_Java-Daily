386. Lexicographical Numbers
Given an integer n, return all the numbers in the range [1, n] sorted in lexicographical order.

You must write an algorithm that runs in O(n) time and uses O(1) extra space. 

 

Example 1:

Input: n = 13
Output: [1,10,11,12,13,2,3,4,5,6,7,8,9]

Constraints: 1 <= n <= 5 * 104


We simulate a preorder traversal of a virtual 10-ary tree (each node representing a number).

Here's how:

Start from count = 1.
At each step:
Add count to the result list.
Try to go deeper (count * 10), which gives the next lexicographical number.
If going deeper exceeds n, backtrack:
If count >= n, move up (count /= 10)
Move to next number (count++)
Skip over trailing zeros using while (count % 10 == 0) count /= 10.
This approach ensures each number is visited in lexicographical order directly, without sorting.

Solution:
class Solution {
    public List<Integer> lexicalOrder(int n) {
        List<Integer> result = new ArrayList<>();
        int count = 1;
        
        for (int i = 0; i < n; i++){
            result.add(count);
            if(count * 10 <= n){
                count *= 10;
            } else {
                if(count >= n) count /= 10;
                count++;
                while(count % 10 == 0){
                    count /= 10; 
                }
            }
        }
        return result;
    }
}
