3443. Maximum Manhattan Distance after K Changes

You are given a string s consisting of the characters 'N', 'S', 'E', and 'W', where s[i] indicates movements in an infinite grid:

'N' : Move north by 1 unit.
'S' : Move south by 1 unit.
'E' : Move east by 1 unit.
'W' : Move west by 1 unit.
Initially, you are at the origin (0, 0). You can change at most k characters to any of the four directions.

Find the maximum Manhattan distance from the origin that can be achieved at any time while performing the movements in order.

The Manhattan Distance between two cells (xi, yi) and (xj, yj) is |xi - xj| + |yi - yj|.

Goal of the Problem:
While walking along the path described by s, what is the maximum Manhattan distance you can reach at any point in time if you’re allowed to change at most k characters of your path?

Manhattan Distance Simple Example:
Manhattan Distance = |x| + |y|

Example: Position (3, -2) → Manhattan Distance = |3| + |-2| = 3 + 2 = 5

Brute Force Approach:
The brute-force approach would be too large for big inputs, but works for small strings. It tries changing up to k characters in all possible positions to all possible directions.
Here we are approaching the question via taking two opposite directions at a time

Python Code:
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        # i, j are main directions, taking two directions at a time
        def solve(i, j, s, k):
            dist = 0
            mx = 0

            for ch in s:
                if ch == i or ch == j:
                    dist += 1
                else:
                    if k > 0:
                        k -= 1
                        dist += 1
                    else:
                        mx = max(mx, dist)
                        dist -= 1

            mx = max(mx, dist)
            return mx

        if k == len(s):
            return k

        # Good directions combinations used
        nw = solve('N', 'W', s, k)
        ne = solve('N', 'E', s, k)
        sw = solve('S', 'W', s, k)
        se = solve('S', 'E', s, k)

        return max(nw, ne, sw, se)
Java Code:
class Solution {
    // a, b are main direction else direction enemy
    private int solve(char a, char b, String s, int k) {
        int dist = 0, mx = 0;

        for (int i = 0; i < s.length(); i++) {
            char ch = s.charAt(i);
            if (ch == a || ch == b) {
                dist++;
            } else {
                if (k > 0) {
                    k--;
                    dist++;
                } else {
                    mx = Math.max(mx, dist);
                    dist--;
                }
            }
        }

        mx = Math.max(mx, dist);
        return mx;
    }

    public int maxDistance(String s, int k) {
        if (k == s.length()) return k;

        // good direction
        int nw = solve('N', 'W', s, k);
        int ne = solve('N', 'E', s, k);
        int sw = solve('S', 'W', s, k);
        int se = solve('S', 'E', s, k);

        return Math.max(Math.max(nw, ne), Math.max(sw, se));
    }
}



Hash Map Approach Solutions:
Since the grid moves are directional, but since you're allowed to change k moves anywhere, a hash table may help if we need to store positions or frequencies but for maximum distance, direct simulation with greedy or prefix sums is typically used.

Python3 Code:
class Solution:
    def maxDistance(self, s: str, k: int) -> int:
        def compute(dir1, dir2, dir3, dir4, k_cnt, dist):
            dist[dir1] += 1 if k_cnt[dir1] > 0 else -1
            k_cnt[dir1] -= 1

            dist[dir2] += 1 if k_cnt[dir2] > 0 else -1
            k_cnt[dir2] -= 1

            dist[dir3] += 1
            dist[dir4] += 1

        if len(s) == k:
            return k

        mx = 0
        k_cnt = [k] * 4
        dist = [0] * 4

        for ch in s:
            if ch == 'N':
                compute(1, 3, 0, 2, k_cnt, dist)
            elif ch == 'E':
                compute(2, 3, 1, 0, k_cnt, dist)
            elif ch == 'W':
                compute(0, 1, 2, 3, k_cnt, dist)
            else:  # 'S'
                compute(0, 2, 1, 3, k_cnt, dist)

            mx = max(mx, max(dist))

        return mx
