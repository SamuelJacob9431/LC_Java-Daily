2434. Using a Robot to Print the Lexicographically Smallest String

Question: You are given a string s and a robot that currently holds an empty string t. Apply one of the following operations until s and t are both empty:

Remove the first character of a string s and give it to the robot. The robot will append this character to the string t.
Remove the last character of a string t and give it to the robot. The robot will write this character on paper.
Return the lexicographically smallest string that can be written on the paper.

 
Understanding in a manner:
You are given a string s. You have two operations:

Push: You can push the first character of s into a stack (like a robot holding a letter).

Pop: You can pop the top of the stack and add it to the output string.

Goal: Use any number of push and pop operations, in any order, such that you end up with the lexicographically smallest possible output string.


a greedy + stack approach:

1. Precompute the smallest char to the right of every index:
lowestCharAfterIdx[i] = min(lowestCharAfterIdx[i + 1], s[i + 1]) (cpp code)

This helps us decide whether we can pop from the stack now or wait.

2. Use a monotonic stack (monoDecrStk) to simulate the robot holding characters.

3. For each character in the string s:

Push it into the stack.

While the top of the stack is smaller than or equal to the smallest future character, pop and add to result.

4. After the loop, empty the stack into the result.

Code:
import java.util.*;

class Solution {
    public String robotWithString(String s) {
        int n = s.length();
        char[] minCharRight = new char[n];
        minCharRight[n - 1] = '{'; // '{' is one after 'z' in ASCII

        // Step 1: Precompute the smallest character after each index
        for (int i = n - 2; i >= 0; i--) {
            minCharRight[i] = (char) Math.min(minCharRight[i + 1], s.charAt(i + 1));
        }

        Stack<Character> stack = new Stack<>();
        StringBuilder result = new StringBuilder();

        // Step 2: Process each character
        for (int i = 0; i < n; i++) {
            stack.push(s.charAt(i));

            // Step 3: Pop from stack if top is <= smallest char in future
            while (!stack.isEmpty() && stack.peek() <= minCharRight[i]) {
                result.append(stack.pop());
            }
        }

        // Step 4: Append any remaining characters in stack
        while (!stack.isEmpty()) {
            result.append(stack.pop());
        }

        return result.toString();
    }
}
