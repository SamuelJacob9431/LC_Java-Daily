2966.Divide Array into Arrays with Max Difference

Question:
You are given an integer array nums of size n where n is a multiple of 3 and a positive integer k.

Divide the array nums into n / 3 arrays of size 3 satisfying the following condition:

The difference between any two elements in one array is less than or equal to k.
Return a 2D array containing the arrays. If it is impossible to satisfy the conditions, return an empty array. And if there are multiple answers, return any of them.

 

Example 1:

Input: nums = [1,3,4,8,7,9,3,5,1], k = 2

Output: [[1,1,3],[3,4,5],[7,8,9]]

Explanation:

The difference between any two elements in each array is less than or equal to 2.

You are given an array nums and an integer k.

Goal:
 Divide the array into groups of 3 such that for each group, the max - min ≤ k.

If possible → Return list of groups.

Else → Return [].


Simply put we can sort the array by putting similar numbers together to form the 'n/3' arrays



Java Code:
import java.util.*;

class Solution {
    public int[][] divideArray(int[] nums, int k) {
        Arrays.sort(nums);
        List<List<Integer>> ans = new ArrayList<>();

        for (int i = 0; i < nums.length; i += 3) {
            if (nums[i + 2] - nums[i] > k) {
                return new int[0][0];  // return empty 2D array if condition fails
            }
            ans.add(Arrays.asList(nums[i], nums[i + 1], nums[i + 2]));
        }

        // Convert List<List<Integer>> to int[][]
        int[][] result = new int[ans.size()][3];
        for (int i = 0; i < ans.size(); i++) {
            List<Integer> group = ans.get(i);
            for (int j = 0; j < 3; j++) {
                result[i][j] = group.get(j);
            }
        }

        return result;
    }
}



Python Code:
def divideArray(self, nums, k):
    nums.sort()  # Sort array for grouping close numbers.
    ans = []     # To store resulting groups.

    for i in range(0, len(nums), 3):  # Jump in steps of 3
        if nums[i + 2] - nums[i] > k:  # max - min of this group > k → Not allowed
            return []
        ans.append([nums[i], nums[i + 1], nums[i + 2]])  # Otherwise, form the group

    return ans  # Return list of groups
